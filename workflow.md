# Git & GitHub workflow

## Vraag 1

Waarom gebruiken developers branches?

zodat later versies gecontroleerd kunnen worden en gemakkelijker voor multi werken

## Vraag 2

Wat is het verschil tussen `git pull` en `git push`?

git pull zal de meeste recentse versie ophalen en de verandering op je pc zetten


git push: je duwed je commits naar github


## Vraag 3

Wat is een Pull Request?

Server zal een vergelijking maken met de files op je pc en de verandering correct zetten

## Vraag 4

Wat is het verschil tussen een Git merge en een GitHub Pull Request?

git merge zal twee branches samen brengen 

pull zal de meeste recenste versie brengen naar je computer
